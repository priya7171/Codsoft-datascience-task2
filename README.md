# IMDb Indian Movie Rating Prediction Using Machine Learning

## Project Overview

This project was completed as **Task 2 of my Data Science Virtual Internship at CodSoft**.

The project focuses on exploring an IMDb Indian Movies dataset, performing data cleaning and preprocessing, conducting Exploratory Data Analysis (EDA), and exploring machine learning regression algorithms for movie rating prediction.

The objective was to understand the dataset, prepare it for analysis, and apply different regression techniques.

## Objectives

- Understand and explore the IMDb Indian Movies dataset.
- Identify and handle missing values.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Apply machine learning regression algorithms.
- Evaluate model performance using the R² score.

## Technologies and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. **Data Collection:** Loaded the IMDb Indian Movies dataset.
2. **Data Cleaning:** Identified missing values and handled them using suitable techniques, including average-value imputation where applicable.
3. **Data Preprocessing:** Prepared the dataset for analysis and modelling.
4. **Exploratory Data Analysis:** Explored patterns and relationships in the movie dataset.
5. **Data Visualization:** Used visualizations to understand the data.
6. **Model Building:** Explored different regression algorithms.
7. **Model Evaluation:** Used the R² score to evaluate model performance.

## Machine Learning Algorithms

The project explored the following regression algorithms:

- Linear Regression
- Decision Tree Regression
- Support Vector Regression (SVR)
- Random Forest Regression
- Gradient Boosting Regression
- AdaBoost Regression
- Extreme Gradient Boosting (XGBoost)


2. Open the project folder:

   ```bash

   ```

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `movie-rating-prediction.ipynb` and run the notebook cells.
