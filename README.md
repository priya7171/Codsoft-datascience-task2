# Codsoft-datascience-task2
Task 2 have the dataset of IMDb India Movies. Every dataset has a story and this set is pulled from IMDb.com of all the Indian movies on the platform. Clean this data by removing missing values or adding average values this process will help to manipulate the data to help with your EDA.
I have used the modules like data processing, r2_score, visualization, Data cleaning, mse etc. and I have use the algorithms like linear regression, decision tree regression, support vector regression, random forest regression, gradient boosting regression, adaptive boosting regression, extreme gradient boosting regression.
